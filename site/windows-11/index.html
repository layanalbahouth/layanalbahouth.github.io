Getting a PC ready for Windows 11

Windows 10 stopped receiving security updates on 14 October 2025, apart from a paid, time-limited extension. That is why moving managed PCs to Windows 11 matters: an unsupported system stops getting protection against newly found vulnerabilities.

1. Check the hardware

Windows 11 needs, at minimum:

  • A 1 GHz or faster 64-bit processor with two or more cores, on Microsoft’s supported list
  • 4 GB of RAM
  • 64 GB of storage
  • UEFI firmware that is Secure Boot capable
  • TPM version 2.0
  • A DirectX 12 compatible graphics card with a WDDM 2.0 driver

Microsoft’s PC Health Check app gives a quick answer on whether a PC is eligible.

2. Switch on TPM and Secure Boot

Some PCs that meet the hardware requirements still fail the check because TPM or Secure Boot is switched off in the firmware settings. Check there before deciding a PC can’t be upgraded.

3. Back up, then install

Formatting erases the disk, so back up the user’s data first. For a single PC, a clean install can be done by booting from USB installation media.

4. Many PCs at once

For a whole fleet, a management tool does the work remotely. Endpoint Central, for example, lists OS deployment among its features; see how its agent works.

الملخص: انتهى دعم Windows 10 الأمني في 14 أكتوبر 2025، فيجب نقل الأجهزة إلى Windows 11. افحص المتطلبات (TPM 2.0 وSecure Boot وUEFI و4GB رام و64GB تخزين)، ثم خذ نسخة احتياطية قبل الفورمات.
