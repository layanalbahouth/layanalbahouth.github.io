Same network, two ways: static routes vs OSPF

Two PCs on two different networks, joined by two routers. Each router only knows the networks plugged into it, so on its own neither PC can reach the other. I built this network twice in Cisco Packet Tracer: once with static routes, once with OSPF. Same addresses, same result, very different way of getting there.

The network

DeviceInterfaceAddress
R1G0/0 (towards PC1)192.168.10.1/24
R2G0/0 (towards PC2)192.168.11.1/24
R1 ↔ R2G0/110.10.10.1 and 10.10.10.2
PC1 / PC2–192.168.10.10 / 192.168.11.11, gateway .1

Way 1: static routes

With static routes, I tell each router by hand where the other network is. Each router needs one line, pointing to the other router’s address on the link between them:

! R1
ip route 192.168.11.0 255.255.255.0 10.10.10.1
! R2
ip route 192.168.10.0 255.255.255.0 10.10.10.2

The routing table on R1 then shows the route with an S:

S    192.168.11.0/24 [1/0] via 10.10.10.1

Way 2: OSPF

With OSPF, I don’t write the route at all. Each router announces the networks it’s connected to, and they learn the rest from each other:

! R1 (R2 is the same, with 192.168.11.0)
router ospf 1
 network 192.168.10.0 0.0.0.255 area 0
 network 10.10.10.0 0.0.0.3 area 0

Once the two routers become neighbours, show ip ospf neighbor lists the other router with the state FULL.

And the same network now appears in R1’s table, this time with an O, learned from R2:

O    192.168.11.0/24 [110/2] via 10.10.10.2

In both versions, a ping from PC1 to PC2 gets 4 out of 4 replies.

What the numbers in brackets mean

The first number is the administrative distance: how much the router trusts the source of a route when it has more than one way to learn the same network. Lower wins. On Cisco routers the default is 1 for a static route and 110 for OSPF, which is exactly what the two tables show. The second number is the metric: 0 for the static route, and an OSPF cost of 2 for the learned one.

Which one, when?

Static routesOSPF
What you configureThe path to every remote network, on every routerThe networks each router is connected to
A new network appearsAdd a route by hand on each router that needs to reach itAdvertise it on the router it’s connected to, and the others learn it
Good fitSmall, simple networks that rarely changeNetworks that grow or change

For two routers, static routes are honestly simpler: two lines and done. The difference shows up as the network grows, which is why the campus lab runs OSPF across its switches instead.

الملخص: نفس الشبكة انبنت مرتين في Packet Tracer. مرة بـStatic routes، كل راوتر نكتب له يدويًا وين الشبكة الثانية، وتطلع في الجدول بحرف S وAD قيمته 1. ومرة بـOSPF، الراوترات تعلن شبكاتها وتتعلم من بعض، وتطلع بحرف O وAD قيمته 110. الـStatic أبسط للشبكات الصغيرة الثابتة، والـOSPF أنسب للشبكات اللي تكبر وتتغير.
