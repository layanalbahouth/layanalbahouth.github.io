What the Endpoint Central agent does, and why it matters

ManageEngine Endpoint Central, from Zoho, is a web-based tool for managing computers from one place. Its features include software deployment, patch management, asset management, remote control and OS deployment.

The agent

The agent is a lightweight program installed on each managed computer. It works as the worker that carries out what the Endpoint Central server asks for.

How it works

The agent contacts the server over HTTPS when the computer starts and then every 90 minutes. Each time, it picks up the actions waiting for it and runs them. Those tasks include configurations, security policies and patch deployments.

Why it matters

The agent is the link between the console and the computer. If it isn’t working on a PC, the patches, software and policies queued for that PC can’t reach it, so a PC can quietly fall behind. Checking the agent is an early step when a device isn’t receiving what it should, for example before a Windows 11 upgrade.
